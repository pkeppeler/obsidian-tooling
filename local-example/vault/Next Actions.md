# Next Actions

Single-action tasks with no multi-step structure. Anything that doesn't earn
its own `## Heading` in `Projects.md` lives here.

Each is inherently a next action — tag it `#next` so it surfaces on the
dashboard; add `#p1`/`#p2` for priority (reserve `#p1` for hot-this-week).

Completed items here are harvested into `Archive/Done <YYYY-MM>.md` by
`sweep-done.py`.
