# Projects

Active multi-step outcomes. Each project is an `## H2` heading with a flat
task list beneath it. The dashboard shows each task's backlink, so the H2
heading renders inline as the project label `(Projects > <name>)`.

Tag exactly **one task per project `#next`** — its single doable-now step.
The dashboard's priority bands surface only `#next` tasks; move `#next`
forward as you finish each step. Add `#p1`/`#p2`/`#p3` for priority (reserve
`#p1` for hot-this-week).

Promote a project to `Projects/<Name>.md` only when it grows past ~10 tasks
or accumulates real reference material; leave a `[[wikilink]]` behind here.

## Example Project

One-line description of the desired outcome.

- [ ] first concrete step #next #p1
- [ ] follow-up step #p2
- [ ] blocked step #waiting
